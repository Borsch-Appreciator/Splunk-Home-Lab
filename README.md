# Splunk Home Lab

This repository documents a hands-on **home SOC lab** built using Splunk Enterprise and Linux endpoints. The lab provides practice in:

- Log ingestion and monitoring
- Alert triage
- Field extraction
- Dashboard creation
- Incident-style investigations
